# 🗳️ CivicMate AI: Empowering the Future of Democracy

**CivicMate AI** is a comprehensive, state-of-the-art election guidance platform designed to make voting accessible, educational, and engaging for every citizen. Built with a focus on localization and artificial intelligence, CivicMate ensures that no voter is left behind.

Check out the live application here:

---

## 🚀 Key Features

### 🌍 Global Localization Engine
Native support for four major languages:
- **English**
- **Hindi (हिंदी)**
- **Marathi (मराठी)**
- **Bengali (বাংলা)**
The entire UI, including the AI assistant and maps, syncs instantly with your language choice.

### 🤖 AI Election Assistant
Integrated with **Google Gemini Pro**, our AI assistant provides real-time, accurate answers to any voting-related queries in your native language.

### 📍 Interactive Polling Maps
Powered by **Leaflet.js** and **OpenStreetMap**, the dashboard features an interactive map that helps voters find their assigned polling stations (including specific support for regions like **Sangli Jath**).

### 📊 Real-Time Dashboard
A personal hub for every voter to:
- Track live election statistics.
- Check their registration eligibility.
- Access verified voter checklists.

### 📚 Education Center
A dedicated module to educate first-time and veteran voters on the step-by-step election process, featuring **Text-to-Speech** support for better accessibility.

## 🛠️ Technology Stack

- **Backend**: Python / Flask
- **Database**: SQLite3 (Production-ready schema)
- **AI Engine**: Google Generative AI (Gemini Pro)
- **Frontend**: Native Javascript (ES6+), Vanilla CSS, HTML5
- **Mapping**: Leaflet.js / OpenStreetMap
- **Containerization**: Docker
- **Cloud Infrastructure**: Google Cloud Run (Serverless)

## 💻 Local Setup & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pradnya1212/project.git
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Set Environment Variables**:
   ```bash
   # Required for AI Assistant
   export GEMINI_API_KEY="your_api_key_here"
   ```

4. **Run the application**:
   ```bash
   python app.py
   ```
