# 🗳️ VoteGuide AI – Election Assistant

## 📌 Problem Statement
This project helps users understand the election process in a simple and interactive way.

## 🎯 Objective
To build an AI-powered assistant that explains election procedures, eligibility, and steps involved in voting.

## 🚀 Features
- AI chatbot for election-related queries
- Step-by-step voting guide
- Eligibility checker
- Simple and user-friendly interface

## 🧠 Approach
The system uses:
- Flask backend for handling requests
- Google Gemini AI for natural language understanding
- Predefined logic for eligibility and guidance

## ⚙️ How It Works
1. User enters a query
2. Backend sends it to AI (Gemini)
3. AI generates response
4. System displays answer

## 📊 Use Case
- First-time voters
- Students learning about elections
- General public awareness

## ⚠️ Assumptions
- Users have basic internet access
- Queries are in English

## 🛠️ Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Google Gemini AI

## 📦 Setup Instructions
```bash
pip install -r requirements.txt
python app.py
```
